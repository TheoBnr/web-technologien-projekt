# web-technologien-projekt
Im Rahmen des Moduls Web-Technologien an der HTW Berlin entwickeln wir eine Webanwendung zur Verwaltung einer persönlichen Film- und Serien-Watchlist.

Nutzer sollen Filme und Serien hinzufügen, ihren jeweiligen Fortschritt verwalten und bereits angesehene Titel bewerten können.
